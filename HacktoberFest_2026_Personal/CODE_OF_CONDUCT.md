# Code of Conduct

## Our pledge

We want this project to be welcoming, respectful, and useful for everyone,
regardless of experience level, identity, background, or location.

## Expected behavior

- Be kind, constructive, and specific in reviews.
- Welcome beginner questions and explain decisions patiently.
- Credit other people's work and respect licenses.
- Focus feedback on the work, never on a person.

## Unacceptable behavior

Harassment, discrimination, personal attacks, trolling, doxxing, sexualized
comments, spam, and knowingly submitting malicious or deceptive changes are
not acceptable.

## Enforcement

Report a concern privately to the repository maintainer through the contact
details in the README or GitHub profile. Maintainers may edit, reject, or
remove contributions that violate this code of conduct.
