## 🤖 How These Projects Were Built

Every project in this repository was built through **AI-assisted development**, and I want to be fully transparent about it:

- **Zero lines of code were typed by hand.** All code was generated by AI assistants (**IBM Bob** and **GitHub's AI tooling**) working inside **VS Code**.
- **Each project started from one single, detailed prompt.** The quality of the result came from the quality of the instructions: the business goal, the dataset, the metrics, the dashboard layout and the expected insights were all defined up front.
- **The human role was direction, not typing.** I chose the problems, defined what "good" looks like, reviewed the output, fixed issues (for example, dataset paths and deployment errors), and shipped the apps live.

### Why this matters

Modern analytics work is moving toward AI-assisted workflows. These projects show that I can:

| Skill | What it looks like here |
|---|---|
| 🎯 **Problem framing** | Turning a business scenario into a precise, buildable specification |
| ✍️ **Prompt engineering** | Getting a complete, working dashboard from a single well-structured prompt |
| 🔍 **Critical review** | Checking AI output, spotting bugs, and fixing them |
| 🚢 **End-to-end delivery** | Version control on GitHub and deployment on Streamlit Cloud |
| ⚡ **Speed** | Moving from idea to live product in a fraction of the traditional time |

> These are **AI-assisted builds** and I present them as exactly that. My hand-written analysis work (SQL, Pandas, EDA, statistics and Forage simulations) lives in separate repositories.

## ▶️ Run Any Project Locally

```bash
# 1. Clone the repository
git clone https://github.com/Himanshu-5680/vibe-coding-projects.git

# 2. Open a project folder (example: Blinkit)
cd vibe-coding-projects/Blinkit-Operations-Analytics-Vibe_coding

# 3. Install dependencies
pip install -r requirements.txt

# 4. Start the app
streamlit run app.py
```
